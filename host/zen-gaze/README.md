# ZenGaze

맥북 카메라로 얼굴 방향을 보고 ZEN 키보드의 출력을 바꿔 주는 메뉴바 앱입니다.

- 맥북 화면을 보면 **USB 출력(이 맥)**
- 다른 컴퓨터 쪽을 보면 **BLE 프로필 n(다른 컴퓨터)**

## 구성

```
맥북 카메라 → ZenGaze ──USB 시리얼──▶ ZEN 오른쪽(central)
                                       ├─ USB  → 이 맥
                                       └─ BLE  → 다른 컴퓨터 (프로필 n)
```

키보드 오른쪽 반쪽을 맥에 **USB로 꽂아 둔 상태**에서 동작합니다.
펌웨어는 `host-output-switch` 스니펫이 들어간 central 빌드가 필요합니다
(`build.yaml`의 `zen_right_*_central` 항목에 이미 추가되어 있음).

## 준비

1. 다른 컴퓨터를 BLE 프로필 하나에 페어링해 둡니다 (예: `&bt BT_SEL 1`).
2. 펌웨어를 빌드하고 오른쪽 반쪽에 굽습니다.
3. 오른쪽 반쪽을 USB로 맥에 연결합니다.

## 카메라 없이 먼저 확인하기

펌웨어가 제대로 들어갔는지 터미널에서 직접 확인할 수 있습니다.
포트가 두 개 보이는데, 하나는 ZMK Studio용이고 하나가 전환용입니다.

```bash
ls /dev/cu.usbmodem*
```

```bash
screen /dev/cu.usbmodemXXXX3 115200
```

`?` 엔터 → `ZEN-HOS 1 U 1 1`처럼 응답하면 전환용 포트입니다.
`B1` 엔터로 BLE 프로필 1, `U` 엔터로 USB로 바뀌는지 확인하세요.
(`screen` 종료: `Ctrl-A` 다음 `K`, `y`)

> 1200 baud로 포트를 열면 부트로더 트리거가 동작할 수 있으니 115200 같은 다른 속도를 쓰세요.

## 앱 빌드와 실행

```bash
./bundle.sh
```

```bash
open ZenGaze.app
```

처음 실행하면 카메라 권한을 묻습니다. 메뉴바 아이콘 메뉴에서:

- **다른 컴퓨터의 BLE 프로필**: 1단계에서 페어링한 프로필 번호(0–3)를 고릅니다.
- **보정 (필수)**: 메뉴를 클릭하고 3초 뒤 "띵" 소리가 나면 그 방향을 1.5초 동안 바라보세요.
  맥북 쪽과 다른 컴퓨터 쪽을 한 번씩 하면 됩니다. **두 방향을 모두 보정해야 자동 전환이 켜집니다.**
  (보정 없이 켜 두면 키보드를 내려다보는 것도 "딴 데 봄"으로 오인할 수 있어서요.)
- **지금 이 맥으로 / 지금 다른 컴퓨터로**: 수동 전환.

## 동작 규칙

- 새 방향을 **0.6초** 이상 유지해야 전환합니다(잠깐 눈길이 가는 건 무시).
- 보정 후에는 두 방향 중 **4° 이상** 더 가까운 쪽으로만 바뀝니다(경계에서 왔다 갔다 하지 않게).
- 얼굴이 안 보이면 **현재 상태를 그대로 유지**합니다.
- 키보드가 (다시) 연결되면 키보드의 현재 출력을 그대로 받아들이고, 그다음 시선 변화부터 전환합니다.
- 연결이 끊긴 동안에는 응답하지 않은 포트를 반복해서 건드리지 않고, `/dev` 목록이 바뀔 때만 다시 찾습니다.

## 프로토콜 (펌웨어 `src/host_output_switch.c`)

줄 단위(`\n` 또는 `\r`)로 보냅니다.

| 명령 | 동작 |
|---|---|
| `U` | USB 출력 선택 |
| `B` | BLE 출력 선택 (현재 프로필 유지) |
| `B<n>` | BLE 프로필 n 선택 후 BLE 출력 |
| `?` | 상태만 응답 |

응답: `ZEN-HOS 1 <U|B> <프로필> <BLE 연결 0|1>`, 실패하면 `ZEN-HOS 1 ERR`.

BLE 프로필이 연결되지 않은 상태에서 `B`를 보내면 ZMK가 자동으로 USB를 계속 씁니다.
연결되는 순간 BLE로 넘어갑니다.
